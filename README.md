🤖 Machine Learning – Part 1

Welcome to my Machine Learning Part 1 repository!

This repository documents my learning journey in Data Science and Machine Learning. Here, I explore the fundamentals of data analysis, data cleaning, data processing, and data preprocessing using Python.

The main goal is to understand how raw data is analyzed, cleaned, transformed, and prepared for Machine Learning algorithms.

📚 Topics Covered
1. Exploratory Data Analysis (EDA)
Understanding datasets.
Univariate, Bivariate and Multivariate Analysis.
Data visualization.
Statistical analysis.
Correlation analysis.
2. Data Cleaning
Handling missing values.
Removing duplicate records.
Detecting and handling outliers.
Handling incorrect data types.
Data consistency.
3. Data Processing
Data filtering and sorting.
GroupBy operations.
Data aggregation.
Merging and joining datasets.
Data transformation.
4. Data Preprocessing
Handling missing values.
Encoding categorical variables.
Label Encoding and One-Hot Encoding.
Feature Scaling.
Normalization and Standardization.
Train-Test Split.
